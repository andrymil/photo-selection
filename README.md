# Photo Selection Assistant

> **Status:** In Progress (Active Development)
>
> **Academic Context:** Bachelor of Science (BSc) Thesis
> **Institution:** Warsaw University of Technology | Computer Science (Artificial Intelligence)

## About The Project

The **Photo Selection Assistant** is a full-stack AI application designed to automatically analyze, classify, and filter photos based on image quality. The core objective of this thesis is to use computer vision algorithms to streamline the photo selection process by automatically detecting and filtering out blurred or low-quality images.

Currently, the project is in the active development phase, focusing on expanding the underlying machine learning models and building the user-facing application.

## Key Features

- **Blur Detection:** A baseline PyTorch computer vision model capable of identifying and classifying image blur.
- **Quality Classification:** (In Progress) Extending models to assess overall photo quality based on multiple visual parameters.
- **Full-Stack User Interface:** (In Progress) An intuitive application allowing users to upload datasets and interface with the underlying AI models seamlessly.

## Tech Stack

- **Machine Learning & Vision:** Python, PyTorch, OpenCV, NumPy
